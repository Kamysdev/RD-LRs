Сделай минимальный Unity 3D прототип игры "Cat Chaos" на C#.

Цель прототипа:
Игрок управляет котом на столе и должен за 60 секунд столкнуть как можно больше предметов со стола. Предметы должны физически двигаться, сталкиваться и падать. За каждый предмет, упавший со стола в специальную зону, начисляется 1 очко.

Проект должен быть максимально простым и быстрым для сборки. Не делай сложную архитектуру, сохранения, меню, анимации, инвентарь, уровни или системы прогресса.

Требования к сцене:
1. Одна игровая сцена.
2. В сцене должен быть стол.
3. На столе должно быть 10 физических предметов.
4. Игрок должен управлять персонажем-котом.
5. Если модели кота нет, используй Capsule или простой placeholder-объект.
6. Под столом должна быть trigger-зона, которая засчитывает упавшие предметы.
7. Должен быть UI с:
   - счётом;
   - таймером;
   - финальным сообщением;
   - подсказкой рестарта.
8. После окончания времени управление блокируется.
9. Клавиша R должна перезапускать текущую сцену.

Геймплей:
- Игрок двигается по поверхности стола с помощью WASD.
- Игрок толкает предметы своим телом.
- Предметы имеют Rigidbody и Collider.
- Когда предмет падает со стола и попадает в FallZone, счёт увеличивается на 1.
- Засчитанный предмет должен исчезать или отключаться, чтобы не засчитываться повторно.
- Раунд длится 60 секунд.
- После окончания времени показывается сообщение:
  "Time is over! Score: X"
- Если игрок сбросил все предметы раньше времени, показывается сообщение:
  "All items dropped! Score: X"

Управление:
- W / S / A / D — движение.
- Left Shift — рывок.
- R — перезапуск сцены.

Технические требования:
- Используй Unity C#.
- Используй 3D Physics.
- Для персонажа можно использовать Rigidbody-based movement.
- Для предметов использовать Rigidbody.
- Для зоны падения использовать BoxCollider с IsTrigger.
- Код должен быть простым и понятным.
- Не использовать сторонние библиотеки.
- Не использовать New Input System, используй классический Input.GetAxis/Input.GetKeyDown, чтобы прототип быстрее заработал.
- Код должен работать в Unity 6 / Unity 6000.x.
- Для сброса скорости Rigidbody используй linearVelocity, а не velocity.

Нужные скрипты:
1. CatPlayerController.cs
2. GameManager.cs
3. FallZone.cs
4. DroppableItem.cs
5. SimpleCameraFollow.cs
6. SceneBootstrapper.cs, если возможно автоматически создать тестовую сцену через код.

Описание скриптов:

1. CatPlayerController.cs

Назначение:
Управляет игроком.

Функции:
- движение по WASD;
- рывок по Left Shift;
- блокировка управления после окончания игры;
- ограничение максимальной скорости;
- сброс позиции игрока, если он упал ниже определённой высоты.

Параметры:
- moveForce;
- dashForce;
- maxSpeed;
- fallY;
- respawnPosition.

Поведение:
- В FixedUpdate считывать направление движения.
- Добавлять силу к Rigidbody.
- Если скорость выше maxSpeed, ограничивать её.
- По Left Shift применять импульс в направлении движения.
- Если игрок упал ниже fallY, вернуть его на respawnPosition и обнулить linearVelocity/angularVelocity.

2. GameManager.cs

Назначение:
Управляет состоянием игры.

Функции:
- хранит счёт;
- хранит оставшееся время;
- знает общее количество предметов;
- обновляет UI;
- завершает игру;
- перезапускает сцену по R.

Параметры:
- roundTime = 60;
- totalItems;
- scoreText;
- timerText;
- messageText.

Методы:
- AddScore();
- EndGame(string message);
- RestartScene();

Поведение:
- В Update уменьшать таймер.
- Если время закончилось, завершить игру.
- Если score >= totalItems, завершить игру.
- После завершения игры запретить управление игроком.
- По R перезагружать текущую сцену через SceneManager.LoadScene.

3. FallZone.cs

Назначение:
Определяет, что предмет упал со стола.

Функции:
- обрабатывает OnTriggerEnter;
- проверяет, есть ли у объекта DroppableItem;
- вызывает метод MarkDropped у предмета;
- сообщает GameManager о начислении очков.

Поведение:
- Если в trigger вошёл объект с DroppableItem и он ещё не был засчитан:
  - отметить его как засчитанный;
  - увеличить счёт;
  - отключить объект или Destroy(gameObject).

4. DroppableItem.cs

Назначение:
Маркер для предметов, которые можно сбрасывать.

Функции:
- хранит состояние isDropped;
- имеет метод MarkDropped();
- предотвращает повторный зачёт одного и того же предмета.

5. SimpleCameraFollow.cs

Назначение:
Камера следует за игроком.

Функции:
- камера следует за Transform target;
- сохраняет offset;
- использует плавное движение.

6. SceneBootstrapper.cs

Назначение:
Опционально: автоматически создать минимальную сцену, если её нет.

Если возможно, сделай скрипт, который создаёт:
- стол;
- игрока-placeholder;
- 10 предметов;
- FallZone;
- Directional Light;
- Camera;
- Canvas с UI.

Если автоматическое создание UI через код получится слишком громоздким, можно вместо этого дать инструкцию, как вручную собрать сцену в Unity.

Требования к объектам сцены:

Player:
- модель кота.
- Rigidbody.
- Collider.
- CatPlayerController.
- Tag: Player.

Camera:
- Смотреть на стол сверху под углом.
- Использовать SimpleCameraFollow.

UI:
- Canvas.
- Text или TextMeshPro, но лучше обычный Unity UI Text, если он доступен без дополнительных настроек.
- ScoreText.
- TimerText.
- MessageText.
- MessageText скрыт в начале игры.

Acceptance criteria:
1. Сцена запускается без ошибок.
2. Игрок двигается по столу.
3. Игрок может толкать предметы.
4. Предметы падают со стола под действием физики.
5. FallZone засчитывает предметы.
6. Счёт увеличивается.
7. Один предмет не может засчитаться дважды.
8. Таймер уменьшается от 60 до 0.
9. После окончания времени появляется финальное сообщение.
10. После окончания игры управление игроком отключается.
11. Клавиша R перезапускает сцену.
12. Код простой, без лишней архитектуры.

Выведи:
1. Полный код всех скриптов.
2. Краткую инструкцию, какие GameObject создать в Unity.
3. Какие компоненты навесить на каждый объект.
4. Какие значения выставить в Inspector.
5. Если используешь SceneBootstrapper, объясни, как запустить сцену через него.
